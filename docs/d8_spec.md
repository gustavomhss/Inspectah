# D8 Vertical Slice — rss_news_minimal

This document binds the D8 slice to Inspectah’s DNA (Blocos 1–4) and Sprint Macro. Inspectah remains Data Hub first: a single RSS source, `rss_news_minimal`, flows through the canonical path (source registry → watcher → Evidence Vault → Field Designer → Explore/Verify) with manifest + SHA-256 for every item as mandated in Bloco 1 §6. The slice reuses the filemap and contracts already approved, so no new semantics are introduced—only the minimal implementation required for one end-to-end path. All automation (T0–T8) must run offline against fixtures to satisfy Bloco 2 determinism; only the manual `bin/run_watcher_once.sh` may hit real RSS endpoints for demo purposes. The watcher obeys idempotência `(source_id, canonical_url, content_hash, extractor_version)` and temporal ordering so T3 invariants stay intact. Evidence bundles and metrics generated here (inspectah_run_latency_ms, inspectah_explore_query_latency_ms) plug directly into the SLO/observability expectations in Bloco 1 §4/§8 and the gate layout of Bloco 2. Outputs will live under `out/evidence/T{N}_d8_*` plus scorecards in `out/scorecards/`, enabling future days (D9–D12) to build on this locked, reproducible slice.
