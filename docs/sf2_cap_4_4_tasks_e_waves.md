# SF2 — Cap.4 Bloco 4 — Waves e Tasks (Planner)

## Waves
- **W0 — Baseline & Deps**: validar ambiente (Prom/Alertmanager/Playwright/IdP), catálogos/SLOs congelados, scripts s30–s34/sf2 executáveis e com rc estrito.
- **W1 — Observabilidade real**: /metrics por fluxo/versão, promtool sem erro, alertas firing/resolution registrados, painel com séries não vazias.
- **W2 — Pilotos E2E reais**: start→canary→promo→rollback para news_v2 e contestacao_v0 via API/UI com catálogo assinado, hash publish/runtime comparado, métricas/logs vivos.
- **W3 — SLO/OracleOps**: SLOs de s33/s34 avaliados via PromQL real; slo_breach simulado gera métrica + evento OracleOps/Truth.
- **W4 — Console/RBAC/rc**: actor/operation_id/catalog_hash obrigatórios, RBAC negativo, scripts/tests sem ignorar rc, UI provider/profile/rollout com estados de erro claros.
- **W5 — Contestação/Truth invariants**: fixture real de contestação passando pela state machine, métricas e auditoria; negativos cobrem estados inválidos.
- **W6 — ORR & Bundle**: scorecards S30–S34 rerodados com PASS REAL/NO-GO, bundle `inspectah_sf2_evidence_bundle.zip` completo, ata de GO/NO-GO.
