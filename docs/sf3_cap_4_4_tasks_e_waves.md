# SF3 — Cap.4 Bloco 4 — Waves e Tasks (Planner)

## Waves
- **W0 — Baseline & Deps**: validar bin/s20–s29/sf3 com shebang + permissão + `set -euo pipefail`; IdP OIDC RS256 (JWKS em `/.well-known/jwks.json`) vivo; roles carregadas; Prom/Alertmanager e Playwright vivos; registrar hashes/commits das fixtures auth/truth/ingest; FAIL imediato se faltar qualquer dependência.
- **W1 — Auth/RBAC**: smoke 401/403/200 com JWT RS256 (iss=inspectah-idp, aud=inspectah-api, TTL 15m); claims sub/role/op_id/exp/iat/iss/aud(+request_id); logs e auditoria JSON com actor/role/op_id/route/status/latency/payload_hash; métricas `auth_requests_total{status,role}` e `auth_latency_seconds` não vazias; IdP ausente = fail-closed.
- **W2 — Consoles/Admin/Ingest**: `npm ci` + build/test rc estrito; Playwright com token real (JWT) cobrindo estados happy/erro/empty/RBAC/429/5xx/promo inválida; smoke API ingest/admin com fixtures reais (hash/commit); métricas ingest_* não vazias; sem mocks.
- **W3 — Truth/Promotion**: state machine PENDING→UNDER_REVIEW→{PROMOTED, CONTESTABLE, REJECTED} com fixture real; payload com hash_manifest SHA256; trajetos válido+inválido (400/409/403/200); métricas `truth_promotion_transitions_total`, `truth_promotion_latency_seconds` (buckets), `truth_promotion_failures_total`; audit com actor/role/op_id/hash.
- **W4 — Observabilidade & UI Evidence**: /metrics não vazias para auth/ingest/admin/truth/ui; promtool + PromQL arquivada para alertas (auth_401_spike, protected_route_unprotected, ingest_errors_rate_gt_5, ingest_requests_zero_30m, admin_ui_5xx, truth_promotion_failures, dashboard_freshness>300s); firing+resolution registrados; painel export JSON/PNG; screenshots Playwright happy/erro/RBAC/429/5xx/empty/promo inválida.
- **W5 — ORR & Bundle**: scorecards S20–S29 rerodados (PASS REAL/NO-GO + motivo), bundle `inspectah_sf3_evidence_bundle.zip` com manifest/hash e README/GO_WITH_RISKS, ata `out/logs/SF3_gov.md`.
